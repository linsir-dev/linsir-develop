# 简介

## 什么是 Linsir Spring Cloud

Linsir Spring Cloud 是一套基于 Spring Cloud Alibaba 的微服务开发框架，旨在帮助开发者快速搭建企业级微服务架构。

## 核心特性

### 1. 服务治理

- **服务注册与发现**：基于 Nacos 实现服务自动注册与发现
- **配置中心**：集中管理所有服务的配置信息
- **服务网关**：统一入口，路由转发，鉴权过滤

### 2. 服务通信

- **负载均衡**：Ribbon 实现客户端负载均衡
- **服务调用**：Feign 声明式 HTTP 客户端
- **异步消息**：RocketMQ 实现异步消息通信

### 3. 服务保护

- **熔断降级**：Sentinel 实现流量控制与熔断降级
- **限流控制**：多种限流策略保护服务稳定性
- **分布式事务**：Seata 实现分布式事务管理

### 4. 可观测性

- **链路追踪**：Sleuth + Zipkin 实现分布式链路追踪
- **服务监控**：Actuator + Prometheus 监控服务指标
- **日志收集**：ELK 日志收集与分析
