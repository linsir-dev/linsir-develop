# 欢迎使用 Linsir ABC 文档

这是 Linsir ABC 项目的文档站点，基于 VitePress 构建。

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建文档
npm run build
```

## 文档结构

```
docs/
├── .vitepress/          # VitePress 配置
│   └── config.ts       # 站点配置
├── guide/              # 指南文档
│   └── index.md       # 指南首页
└── index.md           # 站点首页
```
