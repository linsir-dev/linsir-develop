# 解释器模式 (Interpreter Pattern)

> 给定一个语言，定义它的文法的一种表示，并定义一个解释器

***

## 一、模式概述

### 1.1 定义

解释器模式（Interpreter Pattern）是一种行为型设计模式，它给定一个语言，定义它的文法的一种表示，并定义一个解释器，这个解释器使用该表示来解释语言中的句子。

### 1.2 适用场景

- 当有一个语言需要解释执行，并且你可将该语言中的句子表示为一个抽象语法树时
- 该文法简单，对于复杂的文法，文法的类层次变得庞大而无法管理
- 效率不是一个关键问题

### 1.3 优缺点

| 优点 | 缺点 |
|------|------|
| 易于改变和扩展文法 | 对于复杂的文法难以维护 |
| 易于实现文法 | 执行效率较低 |
| 增加了新的解释表达式的方式 | 应用场景有限 |
