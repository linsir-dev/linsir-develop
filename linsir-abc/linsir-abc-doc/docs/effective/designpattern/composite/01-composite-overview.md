# 组合模式 (Composite Pattern)

> 将对象组合成树形结构以表示"部分-整体"的层次结构

***

## 一、模式概述

### 1.1 定义

组合模式（Composite Pattern）是一种结构型设计模式，它将对象组合成树形结构以表示"部分-整体"的层次结构。组合模式使得用户对单个对象和组合对象的使用具有一致性。

### 1.2 适用场景

- 想表示对象的部分-整体层次结构
- 希望用户忽略组合对象与单个对象的不同，用户将统一地使用组合结构中的所有对象

### 1.3 优缺点

| 优点 | 缺点 |
|------|------|
| 简化客户端代码 | 使设计变得更加抽象 |
| 更容易增加新类型的组件 | 可能限制组件的功能 |
| 符合开闭原则 | 难以限制组件类型 |
