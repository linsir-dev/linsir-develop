## 如何选择学习路径

### 如果你是 Java 初学者

建议按照以下顺序学习：

1. [环境配置](./environment) - 确保开发环境正确
2. [快速开始](./quickstart) - 了解基本概念
3. [JDK 8 Lambda 表达式](../jdk8/lambda) - 掌握函数式编程基础
4. [JDK 8 Stream API](../jdk8/stream) - 学习流式处理
5. [学习路线](./learning-path) - 系统学习所有特性

### 如果你有一定 Java 基础

可以直接深入学习：

1. [JDK 8 新特性概述](../jdk8/) - 快速回顾
2. [JDK 11 新特性概述](../jdk11/) - 学习新特性
3. [进阶指南](./advanced) - 深入理解
4. [面试题](../interview/) - 检验学习成果

### 如果你准备面试

1. [面试题汇总](../interview/) - 查看高频面试题
2. [JDK 8 面试题](../interview/jdk8) - 针对性复习
3. [JDK 11 面试题](../interview/jdk11) - 新特性面试题
4. [最佳实践](./best-practices) - 了解实际应用
