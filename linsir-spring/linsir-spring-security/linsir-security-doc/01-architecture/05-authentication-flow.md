# 认证流程详解

> **版本说明**：本文档基于 **Spring Security 7.0** 编写。
> 
> **7.0 主要变化**：
> - `SecurityContextPersistenceFilter` 已更名为 `SecurityContextHolderFilter`
> - 默认自动保存 SecurityContext，无需配置 `requireExplicitSave(false)`
> - 需要 Spring Boot 4.0+ 和 Spring Framework 7.0+

## 总结

| 阶段 | 核心组件 | 职责 |
|------|----------|------|
| **请求拦截** | Filter Chain | 拦截请求，按顺序执行安全处理 |
| **认证处理** | AuthenticationManager | 协调多个 Provider 进行认证 |
| **用户加载** | UserDetailsService | 从数据源加载用户信息 |
| **密码验证** | PasswordEncoder | 验证密码是否正确 |
| **上下文存储** | SecurityContextHolder | 存储当前认证信息 |
| **授权检查** | AuthorizationFilter | 检查用户是否有权限访问资源 |
