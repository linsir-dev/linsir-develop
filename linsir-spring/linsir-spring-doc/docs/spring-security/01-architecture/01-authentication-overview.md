# Spring Security 认证架构概览

> **版本说明**：本文档基于 **Spring Security 7.0** 编写。
> 
> **7.0 主要变化**：
> - `SecurityContextPersistenceFilter` 已更名为 `SecurityContextHolderFilter`
> - 默认自动保存 SecurityContext，无需配置 `requireExplicitSave(false)`
> - 过滤器链顺序有所调整
> - 需要 Spring Boot 4.0+ 和 Spring Framework 7.0+

## 核心架构组件

Spring Security 的 Servlet 认证架构由以下主要组件构成：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        Spring Security 认证架构                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                    SecurityContextHolder                            │   │
│  │  ┌─────────────────────────────────────────────────────────────┐   │   │
│  │  │                    SecurityContext                            │   │   │
│  │  │  ┌─────────────────────────────────────────────────────────┐ │   │   │
│  │  │  │                   Authentication                          │ │   │   │
│  │  │  │  - Principal (用户主体)                                   │ │   │   │
│  │  │  │  - Credentials (凭证)                                     │ │   │   │
│  │  │  │  - Authorities (权限集合)                                 │ │   │   │
│  │  │  └─────────────────────────────────────────────────────────┘ │   │   │
│  │  └─────────────────────────────────────────────────────────────┘   │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                              ↓                                              │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                  AuthenticationManager                              │   │
│  │  ┌─────────────────────────────────────────────────────────────┐   │   │
│  │  │                   ProviderManager                             │   │   │
│  │  │  ┌─────────────────────────────────────────────────────────┐ │   │   │
│  │  │  │              AuthenticationProvider                       │ │   │   │
│  │  │  │  (DaoAuthenticationProvider,                              │ │   │   │
│  │  │  │   JwtAuthenticationProvider, ...)                         │ │   │   │
│  │  │  └─────────────────────────────────────────────────────────┘ │   │   │
│  │  └─────────────────────────────────────────────────────────────┘   │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                              ↓                                              │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                     Filter Chain                                    │   │
│  │  - AuthenticationEntryPoint (请求凭证)                              │   │
│  │  - AbstractAuthenticationProcessingFilter (认证处理)                │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 核心组件说明

| 组件 | 职责 |
|------|------|
| **SecurityContextHolder** | 存储当前认证用户的安全上下文 |
| **SecurityContext** | 包含当前用户的 Authentication 对象 |
| **Authentication** | 表示用户的认证信息（主体、凭证、权限）|
| **GrantedAuthority** | 用户被授予的权限（角色、作用域等）|
| **AuthenticationManager** | 定义过滤器如何执行认证的 API |
| **ProviderManager** | AuthenticationManager 的最常见实现 |
| **AuthenticationProvider** | 执行特定类型认证的组件 |
| **AuthenticationEntryPoint** | 从客户端请求凭证（重定向到登录页、发送 WWW-Authenticate 等）|
| **AbstractAuthenticationProcessingFilter** | 用于认证的基类过滤器 |

## 认证流程概览

```
┌─────────────┐     ┌──────────────────┐     ┌─────────────────────┐
│   用户请求   │     │   认证过滤器      │     │   Authentication    │
│             │────>│                  │────>│   Provider          │
└─────────────┘     └──────────────────┘     └─────────────────────┘
                                                        │
                                                        ↓
┌─────────────┐     ┌──────────────────┐     ┌─────────────────────┐
│   访问资源   │<────│   SecurityContext │<────│   认证成功           │
│             │     │   Holder          │     │   (存储认证信息)      │
└─────────────┘     └──────────────────┘     └─────────────────────┘
```
